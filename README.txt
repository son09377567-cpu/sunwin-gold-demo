SUNWIN-style demo website package

Deploy on GitHub Pages:
1. Open github.com and sign in.
2. Create a new Public repository named sunwin-gold-demo.
3. Upload index.html from this package to the repository root and Commit changes.
4. Open Settings > Pages.
5. Choose Deploy from a branch, branch main, folder /(root), then Save.
6. Wait a few minutes; your public URL will appear in Settings > Pages.

This is an independent visual demo using virtual coins only. It does not collect real login credentials, take deposits, or support cash withdrawals.
